주요 기능

이런 기능을 사용할 수 있어요

교육 현장에서 꼭 필요한 기능만 담았습니다.

실시간 채팅
전체 · 우리 센터 · 선생님 채널로 나뉜 실시간 채팅. 소식과 질문을 빠르게 주고받을 수 있어요.
접속자 현황 & DM
지금 누가 접속해 있는지 한눈에 확인하고, 친구·선생님에게 1:1 DM을 바로 보낼 수 있어요.
파일 공유
수업 자료, 과제 파일을 채팅방과 별도 파일방으로 손쉽게 주고받을 수 있어요.
등하원 알림 (교사용)
출결번호 4자리만 입력하면 보호자에게 등원·하원 문자가 바로 발송돼요. 발송 이력도 확인 가능.
실시간 알림
새 메시지, DM 수신 시 토스트 알림으로 즉시 확인할 수 있어요. 알림을 놓치지 않아요.
앱처럼 설치 (PWA)
앱스토어 없이 홈 화면에 추가해 일반 앱처럼 실행. Android · iPhone 모두 지원해요.

너구리톡 소개

교육기관에 꼭 맞는
전용 커뮤니케이션 앱

너구리톡은 코스모에듀에서 교육기관 구성원을 위해 개발한 전용 채팅 앱입니다. 일반 메신저와 달리 학생·교사·관리자 역할에 맞는 기능을 각각 제공합니다.

앱스토어 심사 없이 웹에서 바로 배포되는 PWA 방식으로, 교육기관이 새로운 앱을 도입하는 데 따른 부담을 최소화했습니다.

코스모에듀 회원 무료 제공 Android · iPhone 지원 별도 앱 설치 불필요 교육기관 전용 채널 분리
채널 분리 채팅전체·센터·선생님 채널로 구분
등하원 알림 SMS4자리 입력으로 보호자에게 즉시 발송
파일방 운영채팅방 + 별도 파일방으로 자료 관리

설치 방법

앱스토어 없이
30초 만에 설치

웹 브라우저에서 바로 설치할 수 있어요. 업데이트도 자동으로 됩니다.

1
아래 버튼으로 접속하기 "지금 설치하기" 버튼을 눌러 너구리톡에 로그인합니다. (코스모에듀 계정 필요)
2
안드로이드 (Chrome) 화면 상단 설치 아이콘 또는 "나" 탭 → "앱으로 설치"를 누르면 홈 화면에 바로 추가돼요.
3
아이폰 (Safari) 하단 공유 버튼()을 누른 뒤 "홈 화면에 추가"를 선택해주세요.
4
설치 완료 & 실행 홈 화면에 생긴 너구리톡 아이콘을 누르면 일반 앱처럼 바로 실행됩니다.
이용 안내
  • 너구리톡은 코스모에듀 플랫폼 회원이라면 무료로 사용할 수 있습니다.
  • 교육기관(센터) 단위로 채널이 분리되어, 소속 센터의 구성원과만 대화할 수 있습니다.
  • 등하원 알림 기능은 교사 이상 권한에서만 사용 가능합니다.
  • 앱 업데이트는 자동으로 적용되며, 별도의 재설치가 필요 없습니다.
  • 데스크톱(PC/Mac)에서도 동일하게 사용 가능합니다.
